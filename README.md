# SLArch-Extended
Extended SLArch framework for split learning in B5G/6G networks. Implements participant selection under bandwidth constraints with channel-aware (SINR) and data-aware (Earth Mover's Distance) policies. Features parameterized trade-off (φ/β) between link reliability and statistical representativeness. Built on ns-3/5G-LENA.

## Genral Configuration
1. Create a root directory with any name (we used "ns3-split").
2. Inside the root directory, download or clone the entire project.
3. Inside the root directory, download and install the NS-3, then place the netwprk code "ns3_5glena_parallel_batch.cc" into scratch within the ns-3.
4. Get the datasets from the link: https://drive.google.com/drive/folders/1zXjNipWWMTgloCLOnvJvJ4O6V9B-jxHq?usp=drive_link and place them in "ds-15" inside the split subdirectory.
